# M03 採樣與分析設計系統

本模組定義土壤、地下水、土壤氣、地表水、沉積物及其他環境介質之採樣規劃、分析項目選擇、品質保證與報告輸出規則。

## 目標
- 以資料品質目標（DQO）建立可追溯的採樣設計。
- 將污染來源假說、概念場址模式、採樣位置、深度與分析項目連結。
- 區分篩測、確認分析、界定範圍、監測、驗證及背景調查目的。
- 所有自動建議均標示依據、限制、待確認資訊及專業審核狀態。
- 不以產業類型、XRF、PID或單一歷史紀錄直接認定污染。

## 適用工作
- 土污法第8、9條評估調查
- 自行調查、污染查證、控制／整治調查
- Phase II ESA
- 背景濃度調查
- 地下水監測與驗證
- 工廠初勘後採樣設計

## 核心原則
- 採樣點數不得只由面積公式決定。
- 採樣深度不得只以固定深度套用所有場址。
- 分析項目需由證據鏈、污染物特性及法規目的共同決定。
- 方法偵測極限需符合決策門檻。
- 缺乏必要資訊時，系統輸出「待確認／需補充資料」，不得虛構。
