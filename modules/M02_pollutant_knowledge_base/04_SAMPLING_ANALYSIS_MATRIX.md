# 採樣與分析決策矩陣

## 決策順序
1. 確認評估目的：背景調查、污染確認、範圍界定、風險評估、控制／整治設計或驗證。
2. 建立來源—路徑—介質—受體概念模式。
3. 依文件與現勘證據建立候選污染物，不得由產業名稱直接等同全套分析。
4. 選擇採樣介質、位置、深度、時間、方法、品管與實驗室方法。
5. 將法定必測項目與專業加測項目分開呈現。

## 介質與常見用途
| 介質 | 適用目的 | 重要設計條件 |
|---|---|---|
| 表層土壤 | 沉降、散布、回填、直接接觸與重金屬風險 | 深度定義、鋪面、複合樣／單點樣策略 |
| 深層土壤 | 儲槽、管線、滲漏、源區與垂向分布 | 地層變化、地下水位、PID／現場篩測與離散採樣 |
| 地下水 | 溶解相、羽流、受體與整治監測 | 井篩層位、井況、低流量採樣、穩定參數、季節性 |
| 土壤氣 | VOC源區與蒸氣路徑 | 採樣深度、洩漏測試、氣象與地坪條件 |
| 室內／室外空氣 | 蒸氣入侵評估 | 建築調查、背景源、時段與氣象配對 |
| 地表水／沉積物 | 排放、逕流與受納水體影響 | 流況、上下游、雨旱季、沉積粒徑 |
| 廢棄物／污泥 | 來源鑑別與處置 | 異質性、分層、代表性與法規方法 |

## 污染物群組與建議介質
- TPH／BTEX／MTBE：源區土壤、地下水；視揮發性與建築條件納入土壤氣。
- 含氯VOCs：土壤氣、離散深度土壤、分層地下水；必要時評估深部含水層及母體／產物。
- 重金屬：表層及分層土壤；地下水是否分析依溶出、pH／Eh與場址概念模式判斷。
- PAHs／PCB／戴奧辛：多與土壤、灰燼、沉積物及特定設備／燃燒歷史相關。
- PFAS：水、土壤及泡沫使用區；器材與品管須避免含氟材料干擾。

## QA/QC最低要求
- 採樣計畫、點位編碼、座標、深度與時間。
- 樣品容器、保存、運送、持樣時間及交接鏈。
- 現場空白、設備空白、運送空白、複樣與基質品管依方法／目的配置。
- 實驗室認證範圍、方法、定量極限與稀釋資訊。
- 結果低於定量極限時，不得以零值進行平均或趨勢分析。

## 現場篩測使用限制
- PID、FID、XRF及試紙可支援即時決策，但不能在未經認可條件下取代正式分析。
- XRF結果受含水率、粒徑、基質、校正與測量時間影響；鎘等低濃度項目尤其需確認方法能力。
- 篩測與實驗室結果應保存配對樣本及偏差評估。
