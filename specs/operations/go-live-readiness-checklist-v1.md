# Go-Live Readiness Checklist v1

## Product and data
- [ ] MVP scope accepted
- [ ] Required environmental sections available or explicitly unavailable
- [ ] Production sources have approved licenses, mappings and citations
- [ ] Refresh schedules and stale thresholds configured
- [ ] Initial source snapshots validated and checksummed
- [ ] Coverage dashboard reviewed

## Legal and professional
- [ ] Current legal/guidance versions loaded and effective dates tested
- [ ] Article 8/9 output labeled preliminary and review workflow active
- [ ] Control/remediation templates approved by environmental professional
- [ ] Professional approval records and signatures supported

## Security and privacy
- [ ] Tenant isolation and authorization penetration tests passed
- [ ] Secrets stored outside source code
- [ ] Encryption, audit logging, retention and deletion policies active
- [ ] Backup restoration tested
- [ ] Incident contacts and response procedure confirmed

## Quality
- [ ] Unit, integration, contract, GIS, AI, DOCX and end-to-end tests passed
- [ ] Unsupported-claim and citation validation passed
- [ ] Word/PDF export regression passed
- [ ] Accessibility and responsive/mobile checks passed
- [ ] Performance targets met

## Operations
- [ ] Monitoring dashboards and alerts active
- [ ] Monthly synchronization workflow active
- [ ] Rollback and database migration procedures tested
- [ ] Runbook, ownership and escalation paths confirmed
- [ ] Release notes and known limitations published

## Acceptance
- [ ] Minxiong reference acceptance pack passed
- [ ] Product Owner approval
- [ ] Environmental Professional approval
- [ ] Data Steward approval
- [ ] Technical Lead approval

No production launch is allowed with an unresolved critical provenance, legal-version, tenant-isolation, backup-restore or fabricated-content defect.
