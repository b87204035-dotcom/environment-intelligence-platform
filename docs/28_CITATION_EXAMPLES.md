# 28 Citation Examples

These are formatting patterns, not a pre-approved source list.

## Government dynamic dataset — APA 7 pattern
Government Agency. (Year). *Dataset title* [Data set]. Retrieval Month Day, Year, from canonical landing page.

## Government report
Government Agency. (Year). *Report title* (Report number/version). Publisher.

## Online map or GIS layer
Government Agency. (Year or n.d.). *Layer title* [Map]. Dataset/service name. Retrieval date when dynamic.

## Journal article
Author, A. A., & Author, B. B. (Year). Article title. *Journal Title, volume*(issue), pages. DOI.

## In-text use
- Parenthetical: (Agency, 2026)
- Narrative: Agency (2026)
- Multiple sources: (Agency A, 2025; Agency B, 2026)

## System rules
- Store source metadata as structured fields; do not store only a preformatted string.
- Reference list is generated from citations actually used.
- A dynamic source includes access/retrieval date.
- Dataset version and snapshot ID are recorded in the export manifest even when omitted from human-readable APA text.
- Chinese titles remain in the source language unless the selected report policy requires translation.
- Broken or unverified URLs block publication.
