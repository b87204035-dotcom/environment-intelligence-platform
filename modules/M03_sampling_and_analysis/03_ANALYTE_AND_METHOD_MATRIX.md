# 分析項目與方法決策矩陣

## 一、選擇流程
`調查目的 → 來源／活動證據 → 候選污染物 → 介質與傳輸 → 決策門檻 → 分析方法 → 偵測極限與QA/QC`

分析項目須有至少一項可追溯依據。系統不得只因某業別「可能使用」某物質，就宣稱場址必須或已確認存在該污染物。

## 二、候選群組
|群組|代表項目|常見介質|關鍵注意事項|
|---|---|---|---|
|石油碳氫化合物|TPH分段、BTEX、MTBE|土壤、地下水、土壤氣|揮發損失、油品類型、LNAPL|
|含氯VOCs|TCE、PCE、cis-1,2-DCE、VC|土壤、地下水、土壤氣|DNAPL、脫氯產物、低偵測極限|
|SVOCs/PAHs|萘、苯并[a]芘等|土壤、沉積物、地下水|吸附、有機質、基質效應|
|重金屬／類金屬|As、Cd、Cr、Cu、Hg、Ni、Pb、Zn|土壤、地下水、沉積物|總量／價態／溶解態、背景值|
|特定新興污染物|PFAS、1,4-dioxane等|地下水、土壤|低濃度、交叉污染、方法適用性|
|一般水質|pH、EC、DO、ORP、鹼度、主要離子|地下水、地表水|現場量測、穩定判定、保存|
|整治設計參數|TOC、CEC、粒徑、含水率、滲透性|土壤、地下水|工法設計，不可等同污染判定|

## 三、分析方法資料欄位
- 主管機關／標準組織
- 方法編號與版本
- 適用介質及分析物
- 採樣容器、保存方式與保存期限
- 前處理、萃取及儀器
- MDL、LOQ／RL及單位
- 干擾、適用範圍與替代方法
- 實驗室認證範圍
- 生效、修正及停用日期

不得將過期方法或非認證方法默認為正式法規判定方法。

## 四、偵測極限規則
- 報告極限原則上應低於決策門檻；若無法達成，需標示資料限制。
- ND僅表示低於報告極限，不等於零。
- 不同年度或實驗室資料比較前，需檢查方法、基質、單位與報告極限。
- 稀釋造成報告極限升高時，保留原因與是否影響決策的判定。

## 五、價態及分相
- 鉻總量與六價鉻分開管理。
- 溶解態、總量及懸浮固體相關結果不可互相替代。
- 土壤氣、室內空氣及地下水VOCs需分別保存介質與採樣方法。
- TPH不同碳數範圍或方法結果不可未經轉換直接合併。

## 六、分析套組建議輸出
系統可輸出「候選套組」，但必須同時顯示：
- 觸發證據
- 排除原因
- 法規／專案決策用途
- 必要方法版本
- 所需偵測極限
- 專業審核狀態

## 七、禁止規則
- 不得以XRF讀值取代所有正式重金屬分析。
- 不得以PID總反應值判定特定VOC種類或濃度。
- 不得以總鉻直接判定六價鉻。
- 不得以單一總TPH數值推定油品來源或年代。
