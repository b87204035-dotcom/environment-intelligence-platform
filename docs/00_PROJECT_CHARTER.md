# 00 Project Charter

## 1. 產品名稱

- 英文：Environment Intelligence Platform (EIP)
- 中文：地方環境資料庫暨土壤地下水智慧決策平台

## 2. 願景

建立可追溯、可更新、可輸出正式技術報告的臺灣環境資料平台，將政府資料、GIS、法規與環境顧問工作流程整合於同一系統。

## 3. 主要使用者

- 環境工程顧問公司
- 應用地質技師、環境工程技師及相關專業人員
- 企業環安與土地資產管理單位
- 政府機關及研究人員

## 4. 核心使用情境

1. 選擇縣市與鄉鎮市區，產出地方環境基本資料。
2. 輸入地址、地號或 GPS，套疊行政區、航照、地籍、污染場址與敏感區。
3. 產生可直接納入 Word 報告的章節文字、圖、表與參考文獻。
4. 進行土污法第 8、9 條適用性初步判定。
5. 建立控制計畫、整治計畫、監測與驗證文件草稿。
6. 管理案件、現勘照片、文件、版本與歷程。

## 5. 成功指標

- 全臺行政區皆可查詢，並具明確資料完整度標示。
- 所有文字、圖表與判定結果均可追溯至來源。
- 主要動態資料至少每月同步一次。
- 各章預設約 880 字，可由使用者輸入目標字數重新生成。
- Word 匯出內容具標題編號、圖表編號、引用與參考文獻。
- 法規模組不得把 AI 結果表示為主管機關正式認定。

## 6. Version 1.0 範圍

### 納入

- 地方環境資料庫
- GIS 圖台
- 報告產生器
- 資料來源與更新管理
- 第 8、9 條初步判定
- 控制／整治計畫撰寫輔助
- 專案工作區

### 暫不納入

- 取代技師簽證或主管機關審查
- 未取得授權的地籍、航照或商業資料再散布
- 全自動作成具有法律效力的結論

## 7. 產品原則

- Source first：先有來源，後生成文字。
- No fabricated facts：資料不足時明確顯示待確認。
- Human approval：法規、控制與整治文件須由專業人員核定。
- Versioned data：保存來源版本、同步批次與生成版本。
- Mobile field ready：現勘流程需支援 iPhone。
