# M05 土污法與法規規則引擎

## 目的
建立可版本化、可追溯、可人工審核的土壤及地下水污染整治法規則引擎，支援第8條、第9條、公告事業、控制計畫、整治計畫、驗證及解除列管流程。

## 核心原則
- 系統僅提供初步判定與作業輔助，不取代主管機關認定或專業法律意見。
- 每次判定必須綁定法規版本、生效日期、來源網址、證據與缺漏資料。
- 法規、公告、函釋、指引與主管機關個案要求必須分層保存。
- 無法確認時輸出「待確認」，不得強迫二分為適用或不適用。
- 高風險結果必須經環境專業人員或法規審核者核准後，才能進入正式報告。
