# M02 污染物與產業知識庫

## 目的
建立可供地方環境資料庫、土污法第8/9條初步判定、採樣設計、控制計畫、整治計畫與AI報告共用的污染物知識模組。

## 模組文件
- `01_POLLUTANT_MASTER_CATALOG.md`：污染物主目錄與必要屬性。
- `02_INDUSTRY_POLLUTANT_MATRIX.md`：產業／活動與潛在污染物對照。
- `03_FATE_AND_TRANSPORT.md`：環境宿命、傳輸與概念模式規則。
- `04_SAMPLING_ANALYSIS_MATRIX.md`：介質、採樣、保存及分析決策。
- `05_RISK_AND_REPORTING_RULES.md`：風險敘述、證據與報告規則。
- `06_CODEX_INTEGRATION_BACKLOG.md`：後續程式實作契約。

## 核心原則
1. 產業與污染物關聯僅代表「潛在關聯」，不得視為已確認污染。
2. 污染物判定必須保留介質、分析方法、單位、檢出極限、採樣日期及資料來源。
3. 土壤背景濃度、法規標準、場址實測值必須分開管理。
4. AI生成內容只能使用可追溯資料；缺資料時必須揭露限制。
5. 控制或整治工法不得僅由污染物名稱自動決定，必須納入地質、水文地質、濃度、分布、可施工性及法規目標。
