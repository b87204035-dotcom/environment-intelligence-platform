# 23 Field Survey Workflow

## Pre-field
- Create/select project and site/parcels
- Download permitted offline basemap and project layers
- Review data gaps, potential concern areas and required photos/questions
- Define field team, date and safety notes

## Mobile capture
Each observation records:
- project/site
- observation type
- timestamp and device time zone
- GPS coordinate, accuracy and altitude when available
- direction/bearing
- photo/video/voice/note
- category and tags
- observed fact versus investigator interpretation
- creator and edit history

## Offline behavior
- Queue records and files locally
- Show synchronization status and conflicts
- Never silently discard failed uploads
- Preserve original media checksum and metadata

## Map markup
- Point, line and polygon drawing
- Potential source area, drainage, storage, process, staining, waste, well, sampling proposal and access restriction categories
- Area/distance measurement

## Quality control
- Required photo checklist
- Duplicate/blur warning where feasible
- GPS accuracy warning
- Reviewer can accept, request correction or reject

## Post-field
- Synchronize and verify media count
- Generate chronological field log
- Link observations to report sections, risks and proposed sampling points
- Lock approved field record while retaining amendment mechanism

Field observations must not be automatically converted into confirmed pollution findings.
