# 空間分析規則

## 1. 共通輸入

每項分析至少接收：`analysis_id`、`project_id|null`、`input_geometry`、`input_crs`、`target_crs`、`layer_snapshot_ids`、`analysis_parameters`、`requested_by`、`requested_at`。

每項輸出至少包含：結果幾何或統計、來源快照、演算法版本、參數、品質旗標、限制、執行時間及可重現雜湊。

## 2. Point-in-Polygon

用途：地址、地號、GPS 或專案點位歸屬行政區、地質單元、土壤類別、集水區及敏感區。

- 邊界上點位回傳 `boundary`，不得任意歸入單一區域。
- 多層重疊全部回傳，不只第一筆。
- 無交集回傳 `no_match`，不得以最近圖徵代替。

## 3. Buffer

用途：污染場址、河川、井位、基地及敏感區鄰近分析。

- 距離單位為公尺，正式分析在適當投影 CRS 執行。
- 保存原始距離、合併策略、端點樣式及是否消除重疊。
- 緩衝交集僅表示空間鄰近，不代表污染遷移、暴露或法律適用。

## 4. Intersection / Overlay

- 保留來源圖徵 ID、快照及交集面積／比例。
- 幾何修復必須記錄，修復失敗不得偷偷略過。
- 地籍與公告範圍交集需顯示邊界與比例，但最終地號或法律認定仍需人工核對。

## 5. Nearest / Distance

- 回傳直線或測地線距離、最近點、計算 CRS、候選數與最大搜尋半徑。
- 同距離多筆全部回傳。
- 污染場址距離排序不可自動轉換為風險排序。

## 6. 面積與行政區統計

- 儲存原始平方公尺、換算公頃及占行政區比例。
- 面積差異超過容許門檻時標記 `area_mismatch`。
- 行政區變更時依資料有效日期選取邊界版本。

## 7. 水文與地形衍生

- 集水區、流向、坡度與坡向須保存 DEM 來源、解析度、填洼及演算法參數。
- 未經現場水準、井位及水位資料，不得從地形直接推定地下水流向。
- 地下水等水位線需記錄量測日期、井篩層位、潮汐或抽水影響及插值方法。

## 8. 空間查詢狀態

`completed`、`completed_with_warning`、`insufficient_data`、`invalid_geometry`、`crs_error`、`stale_source`、`permission_denied`、`failed`。

## 9. 結果敘述模板

空間結果應使用：「查詢範圍與某圖層存在交集／距離約為 X 公尺」；不得直接寫成「已受污染」、「必然影響」或「依法必須」；後者需結合實測、法規版本及專業審核。
