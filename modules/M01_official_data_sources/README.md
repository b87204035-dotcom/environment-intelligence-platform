# M01 臺灣官方環境資料來源 Catalog

## 模組目的
建立可供地方環境資料庫、GIS、AI報告與資料同步服務共同使用的官方資料來源登錄標準。所有資料必須可追溯、可版本化、可顯示更新狀態，且不得以非官方或未核驗資料冒充正式結果。

## 模組內容
- `01_SOURCE_MASTER_CATALOG.md`：核心來源總表與用途。
- `02_SOURCE_METADATA_STANDARD.md`：每筆來源必填欄位、引用與授權標準。
- `03_REFRESH_AND_FRESHNESS_POLICY.md`：更新頻率、逾期與同步失敗規則。
- `04_FIELD_MAPPING_AND_QA.md`：欄位映射、空間資料與品質檢核。
- `05_CODEX_INTEGRATION_BACKLOG.md`：後續程式介接順序與驗收條件。

## 強制原則
1. 每項資料至少每月檢查一次是否有新版本。
2. 顯示來源機關、資料集名稱、資料期間、發布日期、最後成功同步時間與授權。
3. 原始快照不可覆寫；新版本須另存並保留雜湊值。
4. 更新失敗時保留上一個已發布版本並標示逾期，不得補入虛構資料。
5. AI文字、圖、表與地圖均須能回溯到來源快照與欄位。
6. 法規、公告及高風險判定須經專業人工審核。

## 狀態
本模組為 v1.0 規格，可直接作為 Issue #2、#5、#6、#7、#8 的資料治理依據。
