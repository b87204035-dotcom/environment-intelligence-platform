# 資料品質與驗證規則 v1

## 品質面向
1. 完整性：必要欄位、行政區碼、日期、座標、單位與來源是否齊全。
2. 有效性：型別、範圍、代碼、CRS、日期與幾何是否有效。
3. 一致性：同一來源不同版本、跨來源名稱與代碼是否一致。
4. 唯一性：場址、觀測井、資料批次與版本是否重複。
5. 時效性：是否符合來源更新頻率與平台每月檢查政策。
6. 可追溯性：是否能回溯原始快照、欄位映射、處理程式與發布版本。

## 共通驗證
- 所有資料列必須含 `source_snapshot_id`。
- 日期使用ISO 8601；時間保存UTC並顯示使用者時區。
- 數值必須保存單位，禁止無單位數值進入正式層。
- 空間資料必須保存原始CRS與轉換紀錄。
- 地址與地號解析結果須保存信心值與原始文字。
- 不可變原始快照需有SHA-256。

## 主題規則

### 人口
- 年度／月份不得超出資料來源期間。
- 男女人數、年齡組與總人口不一致時標記警告。
- 行政區界異動不得直接串接趨勢，需註明可比性。

### 氣象雨量
- 測站代碼、位置、高程與資料期間必填。
- 缺測比例超過門檻不得直接計算年統計。
- 站點搬遷或儀器異動需產生斷點旗標。

### 地下水
- 井號、井深、篩管、水位基準與量測日期必填。
- 水位高程需確認基準面，不得混用井口深度與海拔高程。
- 同期測點不足時禁止生成確定流向面。

### 土壤背景濃度
- 分析項目、統計量、單位、樣本數、深度、分析方法、空間母體必填。
- 不同方法或單位不得未轉換即合併。
- 背景值與法規標準需使用不同欄位與顯示樣式。

### 污染場址
- 公告、控制、整治、解除等狀態需符合時間順序。
- 同一場址多公告版本不得互相覆寫。
- 座標缺漏時只能以地址標示，不得虛構中心點。

### GIS
- 幾何需通過有效性檢查。
- 面積與距離運算使用適當投影。
- 直接重疊、鄰近與行政區統計使用不同結果類型。

## 發布門檻
- Critical錯誤：整批隔離，不發布。
- High錯誤：相關主題不發布，保留上一版。
- Medium錯誤：可發布但顯示限制與警告。
- Low錯誤：記錄並列入修正清單。

## 品質報告
每批同步需產生：
- 取得時間與來源版本
- 原始筆數、接受筆數、拒絕筆數
- 各級錯誤數量
- 欄位缺漏率與空間有效率
- 與上一版本差異
- 發布決策與核准人
