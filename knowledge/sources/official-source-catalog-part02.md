# 官方資料來源目錄（第二冊）

版本：v1.0  
用途：補充地方環境基本資料、環境敏感區、土地利用、災害潛勢、自然保育與法規引用所需來源。

## 收錄原則
- 僅納入官方機關、法規資料庫、國家級研究機構或具明確授權之資料集。
- 每筆來源至少記錄：機關、資料集、主題、空間尺度、更新頻率、授權、主要欄位、適用章節、品質風險。
- 未完成授權與欄位核驗者不得上線。

## 第二批來源主題

### 1. 國土利用與土地使用
- 國土利用現況調查成果
- 都市計畫使用分區
- 非都市土地使用分區與使用地類別
- 國土功能分區（正式發布版本）
- 工業區、產業園區及科學園區範圍

適用：行政區概況、土地利用、潛在污染來源、8/9條前置查核。

### 2. 環境敏感區
- 飲用水水源水質保護區
- 水源水質水量保護區
- 自來水水質水量保護區
- 國家公園、自然保留區、野生動物保護區
- 重要濕地、海岸保護區、保安林
- 地質敏感區、活動斷層、山崩地滑敏感區

適用：環境敏感區章節、GIS套疊、開發風險初篩。

### 3. 水文與災害
- 河川、水系、集水區與排水路
- 水庫、湖泊、埤塘與灌排系統
- 淹水潛勢圖
- 土石流潛勢溪流
- 地層下陷監測及地下水管制區

適用：地表水文、地下水、災害潛勢與污染傳輸背景。

### 4. 自然環境與生態
- 植生、森林覆蓋與保育類棲地
- 重要鳥類棲地與生態熱區
- 海岸與濕地基礎圖資

適用：環境敏感區、生態限制與土地開發背景。

### 5. 行政與社經
- 行政區界、村里界、門牌地址
- 戶籍人口、年齡結構、人口密度
- 工商登記與工廠登記公開資料

適用：人口、產業型態、歷史土地使用與潛在污染來源。

### 6. 法規與公告
- 全國法規資料庫
- 環境部法規與行政規則
- 地方政府污染場址公告與解除列管公告
- 控制計畫、整治計畫、驗證及採樣分析相關指引

適用：法規版本控管、8/9條初步判定、控制與整治計畫。

## 品質門檻
1. 官方網址可存取。
2. 授權可供平台使用與報告引用。
3. 更新頻率與最後發布時間可辨識。
4. 空間座標系統與欄位定義清楚。
5. 能保存原始快照與版本。
6. 不得把不同時間基準資料直接合併而不標示。
