# M04 控制與整治計畫知識庫

## 目的
建立控制計畫與整治計畫的結構化知識、審查邏輯、工法篩選、成本期程、監測驗證及風險管理規則，供報告編輯器、AI生成、專業審查與後續Codex實作使用。

## 核心原則
- 所有法規、公告、指引與模板均須版本化並記錄生效日期。
- 系統產出僅為專業草稿，不得取代依法應負責之簽證、審查或主管機關核定。
- 工法建議必須基於概念場址模式、污染物、介質、地層、水文地質、污染範圍、暴露途徑及可施工性。
- 不得以單一污染物名稱直接指定工法。
- 成本、工期與成效均須標示估算基礎、假設、資料缺口與不確定性。
- 控制目標、整治目標、監測指標與驗證標準須分開管理。
