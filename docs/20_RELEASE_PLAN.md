# 20 Release Plan

## v0.1 Foundation
Containerized monorepo, database/PostGIS, backend/frontend skeleton, worker, CI, tests, authentication foundation and documentation.

## v0.2 Trusted Data Core
Source registry, snapshots, synchronization, validation, administrative boundaries, freshness and provenance APIs.

## v0.3 Environmental Database MVP
Required township/district environmental sections, tables/charts/map integration and source display.

## v0.4 Report Builder
Custom-length evidence-grounded narratives, citations, editor, versions and DOCX export.

## v0.5 Project Workspace
Projects, parcels, field data, photos, documents, samples and audit timeline.

## v0.6 Legal and Plan Builders
Article 8/9 decision support plus control/remediation drafting and review workflow.

## v1.0 Production Release
Security review, monitoring, backup/restore test, accessibility review, performance validation, production deployment documentation and approved operating procedures.

Every release uses semantic versioning, migration notes, known limitations, data-source changes and reproducibility notes.
