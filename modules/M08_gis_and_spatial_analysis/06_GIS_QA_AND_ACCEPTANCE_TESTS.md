# GIS 品質檢核與驗收測試

## 1. 匯入品質門檻

| 檢核 | 通過條件 | 失敗處理 |
|---|---|---|
| CRS | 已知且可轉換 | 阻擋正式匯入 |
| 幾何有效性 | 無自交、空幾何或非法座標 | 修復並留紀錄；無法修復則隔離 |
| 臺灣範圍 | 座標落於合理涵蓋範圍 | 標記 out_of_bounds |
| 唯一識別 | feature_id 不重複 | 阻擋發布 |
| 必填欄位 | source、snapshot、日期、授權完整 | 阻擋正式圖層 |
| 時效 | 依來源政策為 current/due/stale | stale 顯示警告，必要時阻擋報告 |
| 面積 | 與來源統計差異在門檻內 | 人工核查 |

## 2. 自動測試

1. WGS84 與 TWD97 TM2 121 往返轉換控制點誤差。
2. 軸序錯置與經緯度顛倒偵測。
3. Point-in-polygon 的內部、外部、邊界及多重重疊案例。
4. 100、500、1,000 公尺 Buffer 面積與單位。
5. Intersection 保留來源 ID、快照及面積比例。
6. Nearest 在同距離、多候選及無候選時的結果。
7. 無效幾何、空幾何及幾何集合處理。
8. 過期資料、來源不可用與權限不足錯誤。
9. 地圖輸出是否具備所有必要元素。
10. 已發布報告是否鎖定原始快照。

## 3. 民雄鄉驗收案例

測試包應包含明確標示的測試幾何：

- 行政區定位及面積彙整。
- 測試地址、地號及 GPS 候選確認。
- 測試基地與地質、土壤、河川、地下水井、污染場址及敏感區套疊。
- 產出鄉鎮尺度與基地尺度地圖。
- 驗證資料來源、資料日期與最後同步時間。

所有測試資料須標示 `synthetic_test_data`，不得冒充官方資料或真實污染結論。

## 4. 驗收門檻

- 100% 正式圖層具來源與快照。
- 100% 距離與面積結果揭露 CRS 與方法。
- 100% 報告地圖具來源、日期、比例尺、指北針與圖例。
- 空間分析不得產生未經證據支持的污染或法規結論。
- 租戶與專案圖層跨權限測試必須全部通過。
- 關鍵轉換與空間分析測試通過率 100%；非關鍵測試依 M10 發布門檻。

## 5. 人工抽查

每次新增主要來源至少抽查：幾何位置、屬性、圖例、日期、行政區交集及原網站對照。法規公告範圍與地籍套疊須由具權限人員複核。
