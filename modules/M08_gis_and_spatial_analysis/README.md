# M08 GIS 與空間分析模組

本模組定義環境智慧平台之 GIS 圖層、座標系統、空間分析、地圖輸出、API 契約與品質驗收規則。適用於地址、地號、GPS 與行政區查詢，並支援地方環境基本資料、污染場址、環境敏感區、地質、水文、地下水、土壤背景、現勘及報告輸出。

## 核心原則

1. 所有空間結果都必須可追溯到資料來源、資料快照與座標轉換紀錄。
2. 污染場址鄰近、交集或緩衝分析僅表示空間關係，不等同確認污染、污染影響或法律責任。
3. 地圖必須顯示圖名、圖例、比例尺、指北針、座標系統、資料來源、資料日期及最後成功同步時間。
4. 正式分析預設以適合臺灣之投影座標系統計算距離與面積，WGS84 僅作交換與定位顯示。
5. 所有圖層均需版本化，原始資料快照不得覆寫。
6. M08 僅屬既定 M01 至 M10 模組之一，不新增其他頂層模組。
