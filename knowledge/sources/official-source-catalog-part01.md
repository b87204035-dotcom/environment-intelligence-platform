# 官方資料來源目錄（第一冊）

版本：v1.0  
建立日期：2026-08-01  
適用專案：Environment Intelligence Platform（EIP）

## 使用原則

1. 本目錄僅收錄可由官方網站、政府資料開放平臺或主管機關系統核驗的資料集。
2. 平台至少每月檢查一次；若來源更新頻率較低，僅顯示「本月已檢查、來源未發布新版」，不得虛構新資料。
3. 每次匯入須保存原始檔、下載時間、來源發布時間、雜湊值、授權資訊及欄位對應版本。
4. 報告引用時應顯示資料集名稱、提供機關、資料期間、來源發布日期、系統最後成功同步時間及存取日期。
5. 所有網址僅作來源登錄；實作前須再確認端點、授權與欄位是否變動。

## 第一批已核驗來源

### SRC-MOENV-001 土壤及地下水污染場址基本資料
- 提供機關：環境部環境管理署
- 政府資料開放平臺資料集編號：6351
- 主題：污染場址、控制場址、整治場址
- 更新頻率：每日
- 主要欄位：場址代碼、場址名稱、公告與解除文號、縣市、鄉鎮市區、場址類型、使用狀態、污染物及濃度、地址、地號、場址面積、公告與解除日期、TWD97座標、WGS84經緯度
- EIP模組：污染場址、行政區環境基本資料、GIS、專案風險分析、報告引用
- 同步策略：每日可抓取；正式產品至少每月完整同步並每日檢查增量
- 資料品質檢查：場址代碼唯一性、座標範圍、公告日期格式、縣市與鄉鎮代碼對照、污染物文字保留原文
- APA範例：環境部環境管理署。（年份）。《土壤及地下水污染場址基本資料》[資料集]。政府資料開放平臺。存取日期：YYYY年MM月DD日。

## 驗收標準

- 每筆來源具唯一代碼。
- 主管機關、名稱、主題、更新頻率、授權、資料期間及適用模組可追溯。
- 不確定或尚未核驗之端點不得標示為可自動同步。
- 報告文字必須引用實際使用的資料快照，而非僅引用本目錄。
