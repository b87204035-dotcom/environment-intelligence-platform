# 產業／活動－潛在污染物矩陣

## 使用方式
本矩陣用於初步盤點、訪談、文件索取與採樣設計。所有對照均為候選關聯，不代表場址實際使用、排放或污染。

| 產業／活動 | 應優先查核的物料／設備 | 候選污染物 | 建議證據 |
|---|---|---|---|
| 加油站、油庫、車隊基地 | 地下儲槽、卸油口、加油島、油水分離設施、管線 | TPH、BTEX、MTBE及油品添加劑 | 儲槽圖、測漏、進銷存、維修與洩漏紀錄 |
| 金屬加工、脫脂清洗 | 脫脂槽、清洗機、溶劑儲區、廢液區 | TCE、PCE、TCA、其他VOCs、油品 | SDS、製程表、設備清單、廢溶劑聯單 |
| 電鍍、表面處理 | 鍍槽、酸鹼槽、污泥區、廢水系統 | Cr、Ni、Cu、Zn、Cd、Pb、CN、酸鹼 | 藥品清冊、操作條件、污泥分析、放流水資料 |
| 印刷、塗裝、黏著 | 油墨、塗料、稀釋劑、洗版液 | VOCs、SVOCs、金屬顏料 | 配方、SDS、採購量、廢液與空污紀錄 |
| 乾洗 | 乾洗機、溶劑桶、污泥／殘渣 | PCE及相關降解產物 | 機型、溶劑採購、維修與廢棄物紀錄 |
| 半導體、電子零組件 | 濕製程、清洗、蝕刻、特殊氣體、廢液 | 酸鹼、含氟物、溶劑、金屬；依製程確認 | 化學品清單、廠務圖、廢液分類、事故紀錄 |
| 電池製造／回收 | 原料儲區、破碎、酸液、集塵灰 | Pb、Cd、Ni、Co、Li、酸液 | 原料、產品世代、廢棄物、土壤粉塵管理 |
| 鋼鐵、鑄造、熱處理 | 熔爐、淬火油、集塵灰、爐渣 | 金屬、TPH、PAHs | 原料、爐渣與集塵灰去向、燃料資料 |
| 木材防腐 | 浸漬槽、藥劑儲區、滴乾區 | As、Cr、Cu、PAHs或其他防腐劑 | 防腐配方、年代、設備與土壤接觸區 |
| 農藥／肥料製造或倉儲 | 原料、混合、包裝、破損區 | 特定農藥、As、Hg、溶劑、氮磷鹽類 | 產品年代、登記成分、庫存與事故資料 |
| 化工原料／樹脂 | 反應、儲槽、裝卸、廢液 | 依單體、溶劑、觸媒與副產品建立清單 | PFD、物料平衡、SDS、儲槽與管線圖 |
| 塑膠加工 | 增塑劑、清洗劑、油品、印刷 | 鄰苯二甲酸酯、VOCs、TPH | 配方、加工溫度、清洗與廢料紀錄 |
| 廢棄物處理／非法棄置 | 堆置區、滲出水、焚燒、破碎 | 依廢棄物來源廣泛篩選 | 聯單、來源、外觀、XRF／篩測及分區採樣 |
| 變電／大型電氣設備 | 變壓器、電容器、油坑 | 絕緣油、PCB（歷史設備） | 設備年代、銘牌、換油與報廢紀錄 |
| 火災或燃燒區 | 燃燒物、灰燼、消防泡沫 | PAHs、金屬、戴奧辛、PFAS（視泡沫） | 火災報告、物料清單、消防紀錄 |

## 對照規則
1. 候選分析項目須能追溯至物料、製程、設備、廢棄物或事故之一。
2. 同一產業因年代、規模與製程不同，候選項目可能完全不同。
3. 歷史航照或土地使用只能支持活動存在，不能證明使用特定化學品。
4. AI輸出必須標示「已證實」「合理懷疑」「一般產業關聯」三種層級。
5. 公告事業業別與分析項目應由版本化法規表管理，不得以本矩陣取代法定要求。
