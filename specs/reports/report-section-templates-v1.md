# Report Section Templates v1

## Common controls for every section
- Target characters: default 880; configurable 100–10,000.
- Tone: technical consultant / academic / regulator-facing / concise.
- Buttons: generate, regenerate, edit, compare versions, copy, approve, export.
- Mandatory display: actual character count, source list, data period, last successful sync, freshness status, limitations and reviewer status.
- Publication gate: no unsupported factual claim; all figures/tables include title, number, unit, source and date.

Each chapter requires: narrative; key-facts table; at least one map/chart when applicable; evidence manifest; APA 7 references.

## Export rules
- DOCX uses heading styles, automatic TOC, cross-references, captions and page numbers.
- Every export includes report metadata, generated/approved dates, data snapshot manifest and revision history.
