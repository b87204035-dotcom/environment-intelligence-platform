# 控制與整治 Prompt Library

## Prompt 清單
| Prompt ID | 用途 |
|---|---|
| CTRL-PLAN-001 | 控制計畫章節草案 |
| CTRL-MEASURE-001 | 緊急與污染控制措施比較 |
| REM-CSM-001 | 概念場址模式摘要 |
| REM-TECH-SCREEN-001 | 整治工法初選與排除 |
| REM-TECH-WEIGHT-001 | 工法加權評選 |
| REM-PILOT-001 | 模場試驗需求與判定條件 |
| REM-COST-001 | 成本項目與不確定性架構 |
| REM-SCHEDULE-001 | 里程碑、相依關係與關鍵路徑 |
| REM-MONITOR-001 | 施工、操作、成效與驗證監測 |
| REM-CONTINGENCY-001 | 行動值、停機、回彈與應變方案 |
| REM-QA-001 | 控制／整治計畫品質檢查 |

## 工法建議輸出契約
每項候選工法至少包含：
- `technology_id`
- 原理與處理介質
- 目標污染物
- 適用地質、水文地質及濃度條件
- 前置資料及必要試驗
- 優點、限制與可能副作用
- 施工與操作需求
- 監測指標
- 失敗模式與應變
- 成本與期程不確定性
- 證據與參考文獻
- 專業審核需求

## 禁止事項
- 不得僅依污染物名稱選定唯一工法。
- 不得在缺乏場址尺度、污染量、地層、地下水、可施工性及法規資料時承諾成效或成本。
- 不得將實驗室、案例或供應商資料直接等同本場址可行性。
- 不得產生未經證據支持的藥劑量、井數、處理年限或整治目標。

## 工法篩選 Prompt 片段
```text
依據已核准 CSM 與 evidence_context，對候選工法進行初選、排除與比較。每一判斷必須指出支持證據、限制、資料缺口及必要模場試驗。輸出至少兩個可行候選方案或說明為何目前無法篩選。結果不得作為施工設計或主管機關核准結論。
```

## 計畫章節生成
控制與整治章節的生成順序應為：證據盤點 → CSM → 目標與法規基礎 → 方案比較 → 設計假設 → 監測與驗證 → 應變 → 成本期程風險 → 專業審核。任何上游章節未核准時，下游結論須標示草案或阻擋狀態。
