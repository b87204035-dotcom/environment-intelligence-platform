# 監控、事件與營運

## 監控項目
- API 可用率、延遲、錯誤率與飽和度。
- 資料同步成功率、延遲、stale 數量與來源異常。
- AI 生成失敗、引用缺漏、證據不足與政策阻擋。
- GIS 工作失敗、幾何錯誤、投影轉換與輸出時間。
- 儲存量、備份、還原驗證、排程與佇列。
- 登入異常、權限拒絕、跨租戶警報與可疑檔案。

## 事件分級
- SEV-1：資料外洩、跨租戶存取、正式資料大規模錯誤、核心服務中斷。
- SEV-2：主要功能不可用、同步長時間失敗、重要報告錯誤。
- SEV-3：局部退化、有替代方式。
- SEV-4：一般缺陷或改善。

## 處理流程
偵測 → 分級 → 指揮官 → 止血 → 證據保存 → 溝通 → 復原 → 驗證 → 事後檢討。SEV-1/2 必須建立時間軸、根因、影響、修復、預防措施與責任人。

## 營運 Runbook
每個排程、同步器、資料庫、儲存、AI、GIS 與報告服務須有健康檢查、重試、人工接管、回復與升級程序。
