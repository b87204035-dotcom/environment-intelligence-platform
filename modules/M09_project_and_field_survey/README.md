# M09 專案管理與 iPhone 現勘模組

本模組定義環境顧問案件、基地、地號、文件、照片、GPS、現勘觀察、採樣、任務、時間軸、審核與稽核的共同規格，並以 iPhone 單機現勘為主要使用情境。

## 模組文件
- 01_PROJECT_WORKSPACE_MODEL.md
- 02_SITE_PARCEL_AND_PARTY_MODEL.md
- 03_MOBILE_FIELD_SURVEY_WORKFLOW.md
- 04_PHOTO_GPS_NOTE_AND_FILE_STANDARD.md
- 05_TASK_TIMELINE_REVIEW_AND_AUDIT.md
- 06_OFFLINE_SYNC_SECURITY_AND_ACCEPTANCE_TESTS.md
- 07_CODEX_INTEGRATION_BACKLOG.md

## 核心原則
1. 客戶案件、基地與地號必須可追溯。
2. 現勘內容分為 A 文件確認、B 客戶口述或 LINE、C 合理推定、D 待確認。
3. 原始照片、文件與音訊不得被覆寫。
4. AI 僅能整理已提供證據，不得自動認定污染、法規適用或地下水流向。
5. 跨租戶資料必須隔離，過去案件不得未經授權進入共用知識庫。
6. 固定維持 M01～M10，不新增其他頂層模組。
