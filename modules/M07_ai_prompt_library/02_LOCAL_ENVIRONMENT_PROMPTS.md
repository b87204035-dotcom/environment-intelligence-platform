# 地方環境基本資料 Prompt Library

## 1. 共通規則
每個章節 Prompt：
- 預設 `target_chars=880`，可自訂 300～5,000 字。
- 僅使用 Evidence Bundle 內的資料。
- 每個事實性段落至少對應一筆 Claim 與 Citation。
- 顯示資料期間、來源發布日期、最後成功同步時間。
- 缺資料時輸出 `insufficient_information`，不可補造。
- 統計分析須說明期間、樣本數、缺值與方法。

## 2. Prompt 清單
| Prompt ID | 章節 | 必要證據 |
|---|---|---|
| ENV-GEOLOC-001 | 地理位置與行政區 | 行政界、座標、面積、鄰接區 |

| ENV-GEOLOGY-001 | 地質 | 地質圖、地層、構造、圖幅說明 |
| ENV-SOIL-001 | 土壤與土壤分類 | 土壤圖、母質、理化性質 |
| ENV-SOILBG-001 | 土壤背景資料 | 採樣深度、樣本數、方法、統計母體 |
| ENV-SURFWATER-001 | 地表水文 | 河川、水體、集水區、流域資料 |
| ENV-GW-001 | 地下水與水文地質 | 觀測井、水位、含水層、補注與流向證據 |
| ENV-POP10Y-001 | 近十年人口 | 年度人口、年齡、密度、村里分布 |
| ENV-CLIMATE10Y-001 | 近十年氣象 | 氣溫、濕度、風、測站距離及完整率 |
| ENV-RAIN10Y-001 | 近十年雨量 | 年／月雨量、極端事件、缺測 |
| ENV-CONTAM-001 | 污染場址 | 官方場址快照、公告狀態、座標 |
| ENV-SENSITIVE-001 | 環境敏感區 | 法定圖層、版本、套疊與距離 |
| ENV-HISTORY-001 | 土壤地下水調查歷史 | 官方報告、計畫、監測與公開文獻 |
| ENV-SYNTHESIS-001 | 綜合分析 | 前述章節已核准內容及限制 |

## 3. 範本
```text
任務：依據 evidence_context 撰寫「{section_name}」。
行政區：{county_name}{township_name}
目標字數：{target_chars}
要求：
1. 先陳述資料範圍與期間。
2. 僅寫可由證據支持的事實。
3. 統計數值需附單位、期間與來源。
4. 合理推論須標示「推論」，並說明依據與限制。
5. 缺資料不得推估或引用不存在的來源。
6. 回傳通用輸出 JSON。
```

## 4. 特殊限制
- 地下水流向僅能在有同期水位、高程校正與足夠井網時敘述。
- 土壤背景濃度不得與法規管制標準混用。
- 污染場址的鄰近或行政區內存在，不代表查詢基地受污染。
- 氣象測站不在行政區內時，須說明代表性與距離限制。
