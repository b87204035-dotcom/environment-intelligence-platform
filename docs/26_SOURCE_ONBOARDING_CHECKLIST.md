# 26 Source Onboarding Checklist

A new source cannot enter production until all items are complete:

1. Publisher and responsible agency identified.
2. Canonical dataset title and landing page recorded.
3. Access method documented: API, file, service, manual or restricted.
4. License, attribution, redistribution and commercial-use terms reviewed.
5. Geographic and temporal coverage recorded.
6. Publication/update frequency and expected release lag recorded.
7. Schema, units, identifiers, CRS and code lists documented.
8. Raw snapshot storage and checksum implemented.
9. Parser and validation tests use real authorized fixtures.
10. Data-quality risks and known limitations documented.
11. Citation template approved.
12. Visible last-update and source-period fields mapped.
13. Failure/retry/stale behavior tested.
14. Change-detection and schema-drift alert implemented.
15. Dataset owner and internal reviewer assigned.
16. Initial import validated against publisher examples or totals.
17. Security/privacy classification completed.
18. Production publication approved.

No undocumented scraping or redistribution is permitted.
