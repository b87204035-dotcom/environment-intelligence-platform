# 資安、隱私、備份與復原

## 安全控制
- TLS 傳輸加密與受管金鑰靜態加密。
- 秘密不得寫入 Repository；使用 Secret Manager 並定期輪替。
- 上傳檔案執行副檔名、MIME、大小、惡意程式與壓縮炸彈檢查。
- 依 OWASP ASVS／Top 10 管理認證、注入、存取控制、SSRF、XSS、CSRF 與供應鏈風險。
- 依賴套件、映像與 IaC 執行漏洞掃描；Critical 漏洞阻擋發布。

## 隱私
個資採目的限制與最少蒐集。GPS、聯絡人、照片、聲音與案件文件須有保存期限、存取目的、刪除／匿名化流程與匯出紀錄。

## 備份
- PostgreSQL：每日增量、每週完整，跨區保存。
- 物件儲存：版本化、不可變保留與 checksum 驗證。
- 原始官方資料快照：不得覆寫。
- 配置、Prompt、Schema 與法規版本由 Git 保存。

## 復原目標
初版目標：核心案件資料 RPO 24 小時內、RTO 8 小時內；正式上線前依商業需求核准。每季執行還原演練並保存證據、耗時、缺失與改善單。
