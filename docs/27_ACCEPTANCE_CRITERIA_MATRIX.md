# 27 Acceptance Criteria Matrix

| Capability | Acceptance criteria |
|---|---|
| Administrative query | County/city and township/district selection resolves to versioned boundary and official identifiers. |
| Environmental sections | All required sections render status, source period, last synchronization, sources, limitations and data products. |
| Narrative generation | Default 880 Chinese characters; custom target; evidence-only generation; actual count and citations returned. |
| Soil background | Values include analyte, statistic, unit, depth, method, population, sample count and applicability. Regulatory limits remain distinct. |
| Ten-year analytics | Exact analysis period, completeness and reproducible calculations are shown. |
| GIS | Layers expose metadata; identify/buffer/overlay work; exports include legend, scale, north arrow, CRS, source and date. |
| Pollution context | Regulatory status and dates are preserved; proximity is not presented as causation. |
| References | Inline citations resolve to registered references and source snapshots; APA 7 is default. |
| Updates | Every active source checked at least monthly; last successful sync and stale state shown. |
| Word export | Editable DOCX contains numbered chapters, figures/tables, references and source manifest. |
| Project workspace | Project, site/parcel, field data, documents, reports, approvals and timeline are permission-scoped. |
| Legal support | Applicable version, evidence, assumptions, missing information and human-review requirement are shown. |
| Control/remediation | Draft structure, technical assumptions, evidence and approval workflow are preserved; no automatic professional approval. |
| Audit | Material reads/exports/writes/approvals and AI generations are traceable. |
| Failure handling | Source and generation failures are visible, retryable where appropriate and never silently replaced with invented data. |
