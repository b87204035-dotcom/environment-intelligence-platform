# 04 API Specification

Base path: `/api/v1`

## Administrative and search
- `GET /counties`
- `GET /counties/{county_id}/towns`
- `GET /towns/{town_id}`
- `GET /geocode?address=`
- `GET /parcels/search?county=&town=&section=&number=`
- `POST /locate` with coordinates

## Environmental profile
- `GET /towns/{town_id}/profile`
- `GET /towns/{town_id}/geography`
- `GET /towns/{town_id}/geology`
- `GET /towns/{town_id}/soil`
- `GET /towns/{town_id}/surface-water`
- `GET /towns/{town_id}/groundwater`
- `GET /towns/{town_id}/population?years=10`
- `GET /towns/{town_id}/climate?years=10`
- `GET /towns/{town_id}/pollution-sites`
- `GET /towns/{town_id}/sensitive-areas`
- `GET /towns/{town_id}/investigation-history`

Every response returns `data`, `sources`, `data_date`, `last_synced_at`, `quality`, and `warnings`.

## Reports
- `POST /reports`
- `GET /reports/{report_id}`
- `POST /reports/{report_id}/sections`
- `POST /report-sections/{section_id}/generate`
- `POST /report-sections/{section_id}/regenerate`
- `POST /report-sections/{section_id}/lock`
- `GET /report-sections/{section_id}/versions`
- `POST /reports/{report_id}/exports` (`docx`, `pdf`, `html`, `md`)

Generation request fields: `target_characters` default 880, `tone`, `citation_style`, `included_source_ids`, `instructions`.

## Projects
- CRUD `/projects`
- CRUD `/projects/{project_id}/sites`
- `/projects/{project_id}/files`
- `/projects/{project_id}/photos`
- `/projects/{project_id}/events`
- `/projects/{project_id}/map-annotations`

## Legal assessment
- `POST /legal-assessments/article-8-9`
- `GET /legal-assessments/{id}`
- `POST /legal-assessments/{id}/approve`

Result status: `likely_applicable`, `likely_not_applicable`, `insufficient_information`. Always include law version, reasoning steps, evidence and disclaimer.

## Control and remediation plans
- CRUD `/control-plans`, `/remediation-plans`
- `POST /plans/{plan_id}/sections/{section_key}/generate`
- `GET /plans/{plan_id}/completeness-check`
- `POST /plans/{plan_id}/exports`

## Sources and operations
- `GET /sources`
- `GET /sources/{source_id}`
- `GET /sync-jobs`
- `POST /sync-jobs/{source_id}/run` (admin)
- `GET /data-freshness`

## API standards
- OpenAPI generated by FastAPI.
- ISO 8601 timestamps with timezone.
- Cursor pagination for large collections.
- Idempotency key for create/generate/export requests.
- RFC 7807-style error responses.
- Authorization enforced by organization and project membership.
