# 04 照片、GPS、筆記與檔案標準

## 1. 原始檔
所有照片、影片、音訊與文件須保存原始檔，不得重新壓縮後取代原始檔。建立 `sha256`, `mime_type`, `byte_size`, `captured_at`, `uploaded_at`, `uploader_id`。

## 2. 照片 Metadata
- `asset_id`
- `project_id`, `site_id`, `field_visit_id`
- EXIF 原始值
- WGS84 經緯度與精度
- 拍攝方向、俯仰角（可得時）
- 拍攝區域與主題標籤
- 說明、證據分類、可見限制
- 原始檔、縮圖與報告用衍生檔關聯

EXIF 缺失時須明確標示，不得以目前位置回填為拍攝位置。

## 3. GPS
保存原始座標、來源座標系統、轉換後座標、精度、定位時間與裝置。手動移動點位須保留原座標及修改理由。

## 4. 筆記與語音
語音轉文字結果屬衍生內容，須連結原始音訊並保存模型或服務版本。人工修訂須保留差異。未確認轉錄不得作為正式事實。

## 5. 文件
文件須保存原檔、版本、來源、取得日期、提供者、保密等級及解析狀態。OCR 或文字解析結果不得覆寫原檔。

## 6. 刪除與保留
一般使用者僅能提出刪除要求；實際刪除採軟刪除與保留期。法律保全、正式報告證據或稽核中的檔案不得刪除。

## 7. 報告引用
報告內照片須具有圖號、標題、拍攝日期、位置、方向、來源資產 ID 與必要限制。裁切或標註版本需可追溯回原始檔。
